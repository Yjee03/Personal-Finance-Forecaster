# 📊 Personal Finance & Savings Forecaster

A Scenario-Based Financial Modeling and Forecasting Tool built using Python. 

This project was developed to bridge the gap between financial theory and practical programming, utilizing concepts learned during my first year as a **Financial Mathematics and Industrial Statistics** undergraduate.

## 💡 About the Project

Traditional future value calculators often assume a fixed interest rate and ignore the impact of inflation. In the real world, purchasing power decreases over time, and market conditions fluctuate. 

This tool goes beyond basic calculations by:
1. **Factoring in Inflation:** It calculates both the **Nominal Value** and the **Real Value** (Purchasing Power) of your future savings.
2. **Scenario Analysis:** Instead of a single rate, it evaluates your investment across three dynamic economic states: Worst-case, Average-case, and Best-case scenarios.
3. **Data Visualization:** It automatically generates a comparative Bar Chart to visually represent how your money grows under different conditions.

## 🚀 Features
- **Dynamic User Inputs:** Enter your initial savings, monthly contribution, time period, and expected inflation rate.
- **Custom Interest Rates:** Define your own rates for the 3 economic scenarios.
- **Automated Math:** Uses Financial Mathematics formulas (Time Value of Money, Annuities) to compute precise future values.
- **Visual Analytics:** Uses `matplotlib` to plot side-by-side comparisons of Nominal vs. Real growth.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Libraries:** `matplotlib` (for Data Visualization)
